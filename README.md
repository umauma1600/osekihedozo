# お席へどうぞ！ 〜カフェ案内係〜

2005年頃のFlashゲーム風の、ターン制パズル「席案内ゲーム」です。
`index.html` をブラウザで開くだけで遊べます（外部ライブラリ・通信なし、オフライン動作）。

## 遊び方

1. タイトル画面で難易度（10組／25組／50組／100組）を選んでスタート
2. 来店リスト（左側）のお客さまを、上から順番に席へご案内します
   - リストは開始時に全組生成され、最初からすべて確認できます
3. 先頭のグループが自動で選択され、案内可能な席が光ります。席をクリックでご案内
4. 席を空けたいときは「待機する」で1ターン送れます（不満+2）

## ターン制ルール

- 案内（または待機）するたびに1ターン経過
- 着席したお客さまはランダムなターン数（3〜8）滞在し、経過すると退店して席が空きます
- 各卓に「あと何ターンで退店するか」が表示されます

## 席のルール

- タバコマークのグループは喫煙ルーム希望、それ以外は禁煙席希望
- 子ども連れグループは喫煙ルームとカウンターには案内できません
- 以下の行動で不満ゲージが上昇します（分割 > 相席 > エリア違い > 待機 の順に大きい）
  - グループを分割して案内する（+14）
  - 相席させる（+9）
  - 希望と違うエリアに案内する（+5）
  - 待機する（+2）
- 不満ゲージが満タンでゲームオーバー。全組を案内しきればクリア

## 店内レイアウト（ドトール風カフェ）

- 禁煙フロア（約4/5）: カウンター1人席×7、2人席×9卓、4人席×4卓
- 喫煙ルーム（約1/5）: カウンター1人席×3、2人席×2卓、4人席×1卓
- カウンター1人席は計10席、総席数52席

## 調整

ゲームバランスの定数（滞在ターン数、不満の増加量、属性の出現率、難易度など）は
`index.html` 内スクリプト冒頭の `CONFIG` にまとめてあります。
