# お席へどうぞ！ 〜レストラン案内係〜

2005年頃のFlashゲーム風のシンプルな「席案内ゲーム」です。
`index.html` をブラウザで開くだけで遊べます（外部ライブラリ・通信なし、オフライン動作）。

## 遊び方

1. 待機列のお客さまグループをクリックして選択（案内可能な席が光ります）
2. 席（テーブル or カウンター）をクリックしてご案内
3. 選択解除は「選択解除」ボタン、Escキー、またはフロアの空きスペースをクリック

## ルール

- タバコマークのグループは喫煙エリア希望、それ以外は禁煙エリア希望
- 子ども連れグループは喫煙エリアとカウンターには案内できません
- 以下の行動で不満ゲージが上昇します（分割 > 相席 > エリア違い > 待たせすぎ の順に大きい）
  - グループを分割して案内する
  - 相席させる
  - 希望と違うエリアに案内する
  - 待機列で長時間待たせる
- 不満ゲージが満タンでゲームオーバー。ステージの全組を案内しきればクリア
- ステージが進むと来店間隔が短くなり、属性持ちグループと総組数が増えます

## 調整

ゲームバランスの定数（滞在時間、不満の増加量、来店間隔、ステージ設定など）は
`index.html` 内スクリプト冒頭の `CONFIG` にまとめてあります。
