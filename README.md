# お席へどうぞ！ 〜カフェ案内係〜

2005年頃のFlashゲーム風の、詰将棋型パズル「席案内ゲーム」です。
`index.html` をブラウザで開くだけで遊べます（外部ライブラリ・通信なし、オフライン動作）。
BGM（`bgm.mp3`）を鳴らす場合は `index.html` と同じフォルダに置いてください。

## 遊び方

1. タイトル画面でモードを選んでスタート
   - **決められたコース**（6面）… ノーミス（★★★）で解ける手作りステージ。難易度カーブつき
   - **ランダム〈鬼〉**（100組）… 本当にランダム。最高難度の腕試し（ノーミスは保証されません）
2. 来店リスト（左側）のお客さまを、上から順番に席へご案内します
   - リストは開始時に全組生成され、各組の**滞在ターン**まで最初からすべて確認できます
3. 先頭のグループが自動で選択され、案内可能な席が光ります。席をクリックでご案内
   - 「待機」はありません。完全情報のパズルとして、最善の席割りを読み切りましょう

## ターン制ルール

- お客さまをご案内するたびに1ターン経過
- 各組の滞在ターンはあらかじめ決まっていて、来店リストに表示されます
- 着席後は各卓に「あと何ターンで退店するか」が表示されます

## 席のルール

- 人型アイコンの色はグループ単位で統一：黒＝一般、緑＝子連れ、赤＝喫煙希望（画面左下に凡例あり）
- タバコマークのグループは喫煙ルーム希望、それ以外は禁煙席希望
- 子ども連れグループは喫煙ルームとカウンターには案内できません
- 以下はすべて「**おてつき**」（一律1ミス）としてカウントされます
  - グループを分割して案内する
  - 相席させる（別グループと同じテーブル）
  - 希望と違うエリアに案内する（喫煙希望⇔禁煙席）
- おてつき **5回でゲームオーバー**。全組を案内しきればクリア
- クリア時の評価：おてつき0回＝★★★、1〜2回＝★★、3〜4回＝★

## 店内レイアウト（ドトール風カフェ）

- 禁煙フロア（約4/5）: カウンター1人席×7、2人席×9卓、4人席×4卓
- 喫煙ルーム（約1/5）: カウンター1人席×3、2人席×2卓、4人席×1卓
- カウンター1人席は計10席、総席数52席

## 設定

タイトル画面右上（プレイ中は上部バー）の「⚙ 設定」から、BGMと効果音の音量を
0%（OFF）〜100%の11段階スライダーで調節できます。設定はブラウザ（localStorage）に保存されます。

## クレジット

- アイコン素材：[ICOOON MONO](https://icooon-mono.com/)（商用利用可・加工可のフリー素材）

## 調整

ゲームバランスの定数は `index.html` 内スクリプト冒頭の `CONFIG` にまとめてあります。

- `MISTAKE_MAX` … おてつきの上限（ゲームオーバーになる回数）
- `COURSES` … 決められたコース。`seed` 固定で毎回同じ配置。`groups`（組数）、
  `stayMin`/`stayMax`（滞在ターン）、`wBig`（4人席を出す重み）、`wSmoke`（喫煙室の重み）、
  `childRate`（子連れ率）、`fill`（席を定員いっぱいに埋める率）、
  `open`（開放する席数：`nsC`/`ns2`/`ns4`＝禁煙のカウンター/2人席/4人席、`smC`/`sm2`/`sm4`＝喫煙）。
  コースは開放席の中で「正しい席割り」から逆生成しているため、**必ずノーミス解が存在します**。
  難易度の主軸は **`open`（＝盤面の広さ）** です。席を絞るほど盤面がタイトになり、
  素直な置き方では詰まなくなります（＝先読みが必要な“詰将棋”に）。閉じた席は「準備中」表示になります。
- `ONI` … ランダム〈鬼〉の生成パラメータ（組数・滞在・グループ人数比・喫煙率・子連れ率）。
  こちらは解の存在を保証しない、純粋なランダム生成です。
